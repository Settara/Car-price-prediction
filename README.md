# Car Price Prediction

Учебный проект по прогнозированию стоимости автомобилей, выполненный в рамках интенсива **ШИФТ «Машинное обучение. Классическое»**.

## Задача

Построить модель регрессии, которая прогнозирует цену автомобиля (`Цена`) на основе его характеристик: года выпуска, пробега, расхода топлива, количества цилиндров, экспертной оценки, количества владельцев, бренда, типа топлива, коробки передач, привода и типа кузова.

## Данные

- Исходная информация была распределена по **48 наборам файлов** в форматах CSV, JSON, XLSX и Parquet.
- При объединении получено **49 679 записей**, после группировки по `car_id` — **8 340 уникальных автомобилей** и 22 столбца признаков.
- Целевые значения `Цена` присоединяются из отдельного файла `y_train_base.csv` по `car_id`.
- В итоговой модели используются **6 числовых и 5 категориальных признаков**.

> **Доступ к данным.** Исходные учебные файлы в репозиторий не включены. Для воспроизведения потребуется законный доступ к исходному набору данных. Столбец `Предложение`, показанный на графиках EDA, **не** является целевой переменной модели и не используется как входной признак.

## Что сделано

1. Объединение разнородных файлов и группировка записей по идентификатору автомобиля.
2. Исследовательский анализ данных: пропуски, описательная статистика, распределения, выбросы, корреляции.
3. Преобразование числовых признаков и заполнение пропусков медианой/модой.
4. One-Hot Encoding категориальных признаков (`handle_unknown="ignore"`).
5. Разделение данных на обучающую и валидационную выборки (80/20). Параметры заполнения пропусков и кодировщик рассчитываются только на обучающей части.
6. Обучение Random Forest и сравнение **шести наборов гиперпараметров**.
7. Создание локального демонстрационного интерфейса с помощью Gradio.

## Результаты

Лучшая из рассмотренных конфигураций `RandomForestRegressor`:

| Метрика | Результат на валидации |
| --- | ---: |
| MAPE | **20,37%** |
| MAE | **6 593,63** (ед. исходной цены) |

Параметры лучшей модели: `n_estimators=1000`, `max_depth=None`, `min_samples_leaf=1`, `min_samples_split=2`, `max_features="sqrt"`, `random_state=52`.

**Как интерпретировать результат:** модель подбиралась по этой же валидационной выборке. Это результат локального эксперимента, **не независимая оценка на отложенном тесте**. Денежная единица исходной целевой переменной не подтверждена, поэтому значения MAE не следует подписывать как рубли.

## Как запустить локально

1. Создайте папку `data/` в корне репозитория. Поместите туда исходные папки `dataset_1/` ... `dataset_48/` (с файлами `data.csv`, `data.json`, `data.xlsx` или `data.parquet`), а также `y_train_base.csv` и `X_test_base.csv`.
2. Установите зависимости:

   ```bash
   python -m pip install -r requirements.txt
   ```

3. Запустите Jupyter и откройте `car_price_prediction_portfolio.ipynb`:

   ```bash
   jupyter lab
   ```

4. Выполните ячейки последовательно. Промежуточный `full_dataset.csv` появится в `data/`, а файл предсказаний — в `outputs/`. Демонстрационный интерфейс Gradio запускается локально в конце ноутбука.

> Для обработки XLSX и Parquet нужны дополнительные библиотеки `openpyxl` и `pyarrow`, которые включены в `requirements.txt`. Обучение на 1000 деревьев и перебор шести конфигураций используют ресурсы компьютера.

## Ограничения и планы улучшения

- Провести отдельную независимую оценку качества или кросс-валидацию после выбора гиперпараметров.
- Перепроверить схему группировки записей `car_id`: `groupby(...).first()` берёт первые непустые значения отдельно для каждой колонки.
- Дополнить EDA анализом зависимости **фактической целевой переменной** `Цена` от признаков.
- Использовать единый `scikit-learn Pipeline` для воспроизводимой предобработки и оценки модели.
- Уточнить единицы измерения исходных цен.

## Статус

Учебный прототип, не предназначенный для реального определения рыночной стоимости автомобиля. Исходные результаты взяты из сохранённого локального запуска ноутбука.
